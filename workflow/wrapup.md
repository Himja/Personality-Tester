# Wrapup

**Trigger**
"wrap up", "done for today", "bye", "thanks", or any natural end phrase.

**Goal**
Make sure nothing from this session is lost.

**Inputs**
The conversation, memory/MEMORY.md, TODO.md.

**Steps**
1. Summarise the session in a few lines.
2. Write it to memory/sessions/<today's date, YYYY-MM-DD>.md. Write it even on a quiet day.
3. Update memory/MEMORY.md to what is true now. New overrides old.
4. Update TODO.md. Add and correct; if rows would be removed, tell me which first.
5. Run git add and git commit with a short message.

**Output**
A dated session log, updated MEMORY.md and TODO.md, one commit.

**Standing rule**
No client names or contact details in the session log; use client codes.
