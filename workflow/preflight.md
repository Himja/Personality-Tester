# Preflight

**Trigger**
"start", "what's on today", "where were we".

**Goal**
Get me oriented fast.

**Inputs**
AGENTS.md, memory/MEMORY.md, newest file in memory/sessions/, TODO.md.

**Steps**
1. Read AGENTS.md and memory/MEMORY.md.
2. Read the most recent file in memory/sessions/ (if none, say so).
3. Summarise where we left off in two or three lines.
4. List what is open in TODO.md.

**Output**
Under ten lines, then stop. Do not ask what to work on; say what is on deck.

**Standing rule**
Keep it short.
