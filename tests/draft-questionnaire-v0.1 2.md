# Scoring key (for H only, do not show clients)

**Step 1. Reverse items.** For items marked R, flip the answer: 1↔5, 2↔4, 3 stays 3 (score = 6 minus answer).

**Step 2. Add up each scale** using the table below.

| Scale | Part | Items | Reverse (R) items | Range |
|---|---|---|---|---|
| Openness | A | 1, 6, 11, 16, 21, 26 | 21, 26 | 6–30 |
| Conscientiousness | A | 2, 7, 12, 17, 22, 27 | 22, 27 | 6–30 |
| Extraversion | A | 3, 8, 13, 18, 23, 28 | 23, 28 | 6–30 |
| Agreeableness | A | 4, 9, 14, 19, 24, 29 | 24, 29 | 6–30 |
| Emotional Sensitivity | A | 5, 10, 15, 20, 25, 30 | 25, 30 | 6–30 |
| Driver | B | 31, 35, 39, 43 | none | 4–20 |
| Connector | B | 32, 36, 40, 44 | none | 4–20 |
| Supporter | B | 33, 37, 41, 45 | none | 4–20 |
| Analyst | B | 34, 38, 42, 46 | none | 4–20 |
| Achievement | C | 47 | none | 1–5 |
| Security | C | 48 | none | 1–5 |
| Service | C | 49 | none | 1–5 |
| Independence | C | 50 | none | 1–5 |
| Creativity | C | 51 | none | 1–5 |
| Status | C | 52 | none | 1–5 |

**Step 3. Read the bands.**

| Part A (6–30) | Band |
|---|---|
| 6–13 | Low |
| 14–22 | Middle |
| 23–30 | High |

| Part B (4–20) | Band |
|---|---|
| 4–9 | Low |
| 10–15 | Middle |
| 16–20 | High |

**Step 4. Build the profile.** Report: the two highest and the lowest Part A scales, the highest Part B work style, and the two highest Part C motivations. Ties: note both and discuss with the client.

**Emotional Sensitivity:** a high score means feeling things strongly. It is not good or bad. Describe it gently, especially to teenagers and parents.

**Data check:** if any item is blank or unclear, do not score. Ask the client to complete it (see workflows/client-session.md).

# Design notes and open questions

- **Where the ideas come from:** general personality ideas (five broad traits, four work styles, core motivations). Every item is newly written. No wording was taken from any commercial test.
- **Labels:** the four work styles (Driver, Connector, Supporter, Analyst) and six motivations are my own labels. I deliberately avoided the names and structure of trademarked tests.
- **No Myers-Briggs-style type yet.** I did not imitate its 16-type format. Decide next session whether you want a named 'type' (e.g. top work style plus top trait) or just a profile.
- **Guesses to confirm:** the number of items (52), the band cut-offs, the scale labels, and the ages this suits.
- **Unvalidated:** scores are consistent in design but untested. Pilot with a few clients, and ask each whether the result felt right.
- **Changing wording later:** rewording items while keeping the same scales and scoring keeps results roughly comparable, but re-check after any big change.
- **Next session:** refine items, decide the type label, add the career-interest section, then release as a beta.
